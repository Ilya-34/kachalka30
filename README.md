# Тоннаж

Веб-приложение «Тоннаж»: выбираешь дату начала тренировок, тренируешься в понедельник, среду и пятницу, записываешь подходы и смотришь прогресс.

- Один файл `index.html`, без сборки и серверов.
- Все данные хранятся в браузере участника (localStorage), на сервер ничего не отправляется.
- Устанавливается на экран «Домой» (PWA), работает без интернета.
- Резервная копия: кнопка «Сохранить копию» в приложении.
- Стиль: пиксель-арт, герой Бро Борис (спрайты в `img/`, шрифты Rubik и Press Start 2P в `fonts/`, всё хранится в репозитории, внешних зависимостей нет).
- Режимы: мужской и женский (палитра и герой), русский и английский язык, переключаются в настройках.
