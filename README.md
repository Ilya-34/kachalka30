# Тоннаж

Веб-приложение «Тоннаж»: выбираешь дату старта, тренируешься в понедельник, среду и пятницу, записываешь подходы и смотришь прогресс.

- Один файл `index.html`, без сборки и серверов.
- Все данные хранятся в браузере участника (localStorage), на сервер ничего не отправляется.
- Устанавливается на экран «Домой» (PWA), работает без интернета.
- Резервная копия: кнопка «Сохранить копию» в приложении.
